# Security Policy

## Reporting a vulnerability

Please do not publish security vulnerabilities, credentials, license keys, tokens, or other sensitive information in public GitHub issues.

For security-related reports, contact the project maintainer privately through the official contact channel associated with the Veltrix37 project.

## Scope

Security reports may include issues affecting:

- License activation and validation
- Authentication or authorization
- API security
- Sensitive data exposure
- Update or release integrity
- Other vulnerabilities that could affect Veltrix37 users

Thank you for helping keep Veltrix37 secure.
